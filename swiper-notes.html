任务一 · 提示词工程师：2 轮迭代翻译 wySw4 需求

无缝循环3.2s 自动翻页且手动不停圆点可点初始 cube

本任务不写代码，只把课堂需求翻译给 AI。每轮回答都亲自粘到页面里验证过。

第 1 轮 · 初版提示词

🧑‍💻 我（提示词）

请帮我写一份 Swiper 初始化代码：目标容器 #wySw4，要求无缝循环播放、每 3.2 秒自动翻页一次、底部圆点分页器且圆点可以点击跳转、初始切换效果为 cube 3D 立方体、切换动画时长 800 毫秒。

🤖 AI 第 1 轮回答
new Swiper('#wySw4', { loop: true, speed: 800, effect: 'cube', autoplay: { delay: 3200 }, // ← 第 1 轮的隐患在这里 pagination: { el: '#wyPag4', clickable: true } });
🔍 我的第一轮验证（粘到页面实测）

结论：自动翻页和圆点没问题，但第 ② 条“手动操作后不停”不满足——用鼠标拖过轮播一次后，轮播就再也不自己翻了。原因是 autoplay 默认 disableOnInteraction: true，用户一碰就永久停播。需要返工第 2 轮。

第 2 轮 · 修正提示词（点名要害）

🧑‍💻 我（提示词）

你上一轮的代码有一个 bug：用户拖动轮播之后，自动播放就永远停止了。请修正——要求用户手动滑动/点击之后，自动播放必须继续，不能停；其余要求不变（#wySw4、无缝循环、3.2 秒间隔、圆点可点、初始 cube、800 毫秒）。

🤖 AI 第 2 轮回答
new Swiper('#wySw4', { loop: true, speed: 800, effect: 'cube', autoplay: { delay: 3200, disableOnInteraction: false // ← 关键修正 }, pagination: { el: '#wyPag4', clickable: true } });
🔍 我的第二轮验证

结论：全部通过——手动拖动、点圆点之后再等 3.2 秒，轮播照常自己翻页；循环无缝、cube 立方体效果正常。最终代码已实际写进 swiper-task.html 任务 4。

💡 经验：AI 第一次最容易漏掉 disableOnInteraction 这个参数。提示词里把“手动操作后仍要继续播放”单独强调成一条硬性要求，就能逼 AI 把它写全。

任务二 · creative 自创变换：电影片场效果

官方 demo 257 仿写第 7 个按钮已上线

读懂官方 effect-creative 演示后自创“电影”效果：当前卡片像片尾字幕一样向左移出屏幕并带角度退场，下一张从右侧带着镜像角度滑入，像电影里剪辑转场。数字自定：平移 120%（保证完全出画）、z 轴旋转 ±18°、加投影增加层次。

creativeEffect: { prev: { shadow: true, translate: ['-120%', 0, -300], rotate: [0, 0, -18] }, // 退场：左移 + 左倾 next: { shadow: true, translate: [ '120%', 0, -300], rotate: [0, 0, 18] } // 进场：右入 + 右倾（镜像） }
💡 prev 控制“当前这张离开时怎么动”，next 控制“下一张进来时从哪儿来”。translate 数组是 [x 轴， y 轴， z 轴]（像素或百分比），rotate 是 [x, y, z] 三轴角度（度）。

任务三 · 综合作答：新展品 + 新能力

第 6 展品：爱达·魔都号keyboard 键盘控制

初始提示词

🧑‍💻 我（提示词）

两件事：① 为光影展添加第 6 件展品“爱达·魔都号”（2024 年 1 月首航的国产首艘大型邮轮），展品图用 AI 生成，横版 16:9，slide 结构与其它展品一致（图 + 标题说明条）；② 挑一个课堂上没讲过的 Swiper 能力加上：keyboard 键盘控制 / mousewheel 滚轮 / zoom 双击缩放 / parallax 视差，四选一。

🤖 AI 第 1 轮回答

生成邮轮展品图 swiper-imgs/adu_1.jpg（16:9），把展品 slide 加进 #wySw1 光影展轮播；新能力选用 keyboard，给 #wySw1 加上 keyboard: true。展品说明条与其它展品风格一致。

追加往返 1 · 展品覆盖面

🧑‍💻 我（提示词）

第六件展品每一个动画上面都要有。

🤖 AI 回答

把爱达·魔都号 slide 补进全部四个轮播 #wySw1–#wySw4，每个轮播的说明文案按各自风格单独写（如“海上移动城市 · 国产首艘大型邮轮首航”“乘风破浪 · 驶向深蓝”“邮轮也来试试七种效果”）。实测四轮播均为 6 张展品。

追加往返 2 · 键盘控制覆盖面

🧑‍💻 我（提示词）

键盘控制也加上。

🤖 AI 回答

keyboard: true 加进四个轮播的初始化配置；特别注意 #wySw4 切换效果是“销毁旧实例再重建”，重建配置 cr_conf4 里也必须保留 keyboard，否则一点效果按钮键盘控制就丢了。

💡 最终成果：四个轮播均为 6 件展品 + 方向键翻页；#wySw1 配置 new Swiper("#wySw1", { keyboard: true })，方向键 ←/→ 即可翻页，实测有效。
