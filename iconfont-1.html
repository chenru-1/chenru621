排印原理

这里的每一枚图标都是一枚"活字"：字形被铸进字体文件（woff2 / ttf）， 通过 CSS 类名从字模中取出、排版上版。放大页面不会模糊，因为它们本质是字体。

写法为 <i class="fa-solid fa-house"></i>， 字体内部以码位对应字形：宅 fa-house = \f015、 心 fa-heart = \f004、 Git fa-github = \f09b。
